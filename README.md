# CTW3 local web client

Браузерный BLE-клиент для поилки PETKIT CTW3UV (Eversweet Max 2 UVC).
Работает локально по Web Bluetooth, без облака и без аккаунта PETKIT.

На iOS нужен браузер с поддержкой Web Bluetooth (Safari её не умеет) — например Bluefy.

Секретов в коде нет: ключ авторизации устройства вводится в браузере и хранится
только в localStorage телефона, никуда не отправляется.

Что умеет: статус, уровень воды числом, подсветка и яркость, «не беспокоить»,
режим, пауза, сброс счётчика фильтра, снятие флага isLock, выгрузка истории питья.

Команды 73 (переинициализация), 83 (OTA) и 84 (запись часов) заблокированы в коде.
